## 一、提示词（直接复制这一整段）

```
你是一名学术汇报 PPT 设计师。请为我制作一份课堂汇报 PPT，主题是「赛博小镇：多智能体叙事系统的可治理性设计」（工程实践 B 自命题型）。

【风格要求 · 最高优先级】
严格沿用你上一份《MedLA_文献汇报PPT》的视觉规范，不要另起一套风格。具体做法：
1. 先从我上传的 MedLA 那份 pptx 中提取并复述它的版式规范：母版比例、封面结构、
   标题栏位置与高度、正文区域的栅格（几栏）、配色（主色/辅助色/强调色的十六进制）、
   字号层级（标题/正文/图注/页脚）、页脚样式、留白比例。
2. 然后把同一套规范套用到新内容上——**保留规范，替换内容**，不要只改文字而破坏版式。
3. 如果那份 pptx 不在上下文里，请先向我要，不要凭空猜风格。

【字体 · 硬性要求】
- 中文：阿里巴巴普惠体 3.0 65 Medium。标题与强调文字加粗，正文常规。
- 英文与数字：Times New Roman。
- 同一段落内中英混排时，分别设置对应字体（不要整段统一成一个字体）。
- 正文字号不小于 20 pt，标题不小于 32 pt，图注不小于 16 pt，页脚不小于 12 pt。

【内容来源 · 不得编造】
- 内容全部来自我上传的《PPT_MATERIALS.md》与《PRACTICE_B_REPORT.md》。
- 所有数字必须与素材包「数字清单」完全一致，禁止四舍五入、换算、补充或推测任何新数字。
- 禁止出现「显著提升」「效果更好」「用户体验优化」这类没有对应数据的判断句。
- 任何一处你无法从材料里找到依据，就停下来问我，不要自己补。

【结构 · 共 8 页（16:9）】
P1 封面：主标题「赛博小镇：让 NPC 说了不算」+ 副标题 + 姓名学号 + 日期 + 仓库地址
P2 问题：三处原始缺陷（好感度由模型定 / 记忆按 NPC 存导致串台 / NPC 之间无关系）
    对比「模型提议 → 后端裁决」一句式结论
P3 AUP 云端预演：平台、2×2 设计、延迟 1542→4810 ms（3.12×）、861→1078 ms（1.25×）
    配图 fig1
P4 记忆有没有用：跨轮真实召回 0%→100%、污染率 0、角色一致性 100%，配图 fig2
P5 四层治理总览：①权威状态 ②可追溯记忆 ③关系图 ④场景引擎（表格，每层一句话 + 一个数字）
P6 证据一：动作提议 0 次 vs 15 次、越权采纳 0 次、四个场景判据全过，
    并原文引用三条被拒记录（保留等宽字体），配图 fig3
P7 证据二：伪造记忆可信度 0.20 → 76 字符未进 prompt；抬到 0.90 → 197 字符进入，配图 fig4
P8 边界与下一步：关系不从对话自动推断、可信度无自动事实校验；下一步场景重复取通过率 +
    机制消融 + 真人评测；页脚放仓库地址

【图 · 重点】
1. 我已提供重绘后的 fig1–fig4（200 dpi，配色统一，字体为阿里巴巴普惠体）。
   **优先直接使用这四张 PNG**，按 P3/P4/P6/P7 的位置放置，不要裁掉图中文字标注。
2. 如果你认为必须重绘：只能用我给的数据重画（用 PowerPoint 原生图表或矢量重绘），
   必须保持数值、坐标轴单位、倍数标注完全一致。
3. **严禁用 AI 生图（如 Nano Banana / Imagen）来表现数据**——数字会被画错。
   AI 生图只允许用于纯装饰性背景，且不得遮挡正文与图表。
4. 图注格式：「图 N · 一句话结论（数据来源：AUP 实测 / 本地 Ollama 实测）」。

【可编辑性】
- 交付 .pptx，且所有文本、形状、表格、图表均为**原生可编辑对象**，不要整页贴图。
- 图表优先用 PowerPoint 原生图表（数据可改）；用 PNG 时保持 200 dpi 以上。

【交付流程】
第一步：先输出「逐页大纲」（页码 / 标题 / 3–5 个要点 / 用哪张图 / 演讲备注 60–90 字），
        等我确认后再生成幻灯片。不要一次直接给成品。
第二步：确认后生成 8 页，并为每页写演讲备注（口语化、可照读）。
第三步：交付前自检并列出结果：① 每页字数是否超框 ② 字体是否按要求分别设置
        ③ 8 个数字是否与清单一致 ④ 是否出现禁止的断言 ⑤ 图注是否标了数据来源。

【沟通要求】
如果缺少材料、看不清那份 MedLA 的版式、或某项要求彼此冲突，先问我，不要自行取舍。
```
