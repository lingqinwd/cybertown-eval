# 图表数据规格（给 Gemini 自己画图用）

> 用法：和《PPT_CONTENT_6P.md》一起上传。**图由你按本文件的数据生成，
> 不要引入任何本文件之外的数字。** 优先用 PowerPoint 原生图表（可编辑）。

---

## 总则

| 项 | 要求 |
|---|---|
| 图表类型 | 原生柱状图 / 堆叠条 / 关系示意图；**不要 3D、不要阴影、不要渐变** |
| 配色 | 云端/主色 `#1E4E8C`；关/基线 灰 `#9AA9BA`；绿「通过」`#2E9E5B`；红「被拦」`#B8332A`；橙「异常」`#D48817`；灰蓝「条件不满足」`#6B7C90` |
| 数值标签 | 每根柱/每段必须标数值，字号不小于图内正文 |
| 网格 | 只保留水平浅虚线，颜色 `#DDE3EA` |
| 字体 | 中文 阿里巴巴普惠体 3.0 65 Medium；英文数字 Times New Roman |
| 图注 | 必须含「数据来源：AUP 实测」或「数据来源：本地 Ollama 实测」 |
| 禁止 | 不得增删数据点、不得改数值、不得四舍五入、不得用 AI 生图表现数据 |

- 条右侧标「合计 15 次」
