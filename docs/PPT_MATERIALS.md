## 二、先把这段粘给 Gemini

```
你是学术汇报 PPT 设计师。请根据我上传的《PPT 制作素材包》和 5 张图，制作一份中文课堂汇报 PPT。

硬性要求：
1. 共 8 页，16:9 版式。
2. 每页标题不超过 12 个字；正文每页不超过 5 个要点，每个要点不超过 20 个字。
3. 每页必须写演讲备注（60–90 字，口语化，可直接照读）。
4. 所有数字必须与素材包完全一致：1542、4810、861、1078、3.12×、1.25×、0%、100%、
   76、197、0.20、0.50、0.60、0.95、15、5、100 个、143、35、4。
   ——禁止四舍五入、禁止改写、禁止补充任何我没提供的数字。
5. 图片按素材包指定的页码放置，不要裁掉图中的文字标注，不要重绘数据图。
6. 配色：深蓝 #1F3352 主色、浅灰 #F4F6F8 背景块、强调色只用两种
   （红 #E05252 表示"被拦下/代价"，绿 #3FA45B 表示"通过/收益"）。不要用渐变和花哨动效。
7. 字体：标题黑体，正文思源黑体/微软雅黑；正文不小于 20 pt，标题不小于 32 pt。
8. 禁止出现"显著提升""效果更好""用户体验优化"这类没有数据的断言。

输出格式：
先输出「逐页大纲」（页码 / 标题 / 要点 / 用哪张图 / 备注），我确认后你再生成幻灯片。
```

确认大纲后，把下面「三、逐页内容」整段发给它。

## 三、逐页内容

### 第 1 页 · 封面

- 主标题：**赛博小镇：让 NPC 说了不算**
- 副标题：多智能体叙事系统的可治理性设计（工程实践 B）
- 底部：姓名 / 学号 · 日期 · 开源仓库 `github.com/lingqinwd/cybertown-eval`
- 无图
- 备注：今天讲的不是"我做了个游戏"，而是"我怎么让大模型不能随便改游戏状态"。

### 第 2 页 · 问题：模型既生成内容，又决定状态

- 三个原始缺陷：
  1. 好感度由模型一句话决定
  2. 记忆按 NPC 存 → 不同玩家串台
  3. NPC 之间没有关系
- 一句话结论：模型提议 → 后端裁决
- 图：无（用三个色块对比"改造前 / 改造后"）
- 备注：这三条都不是猜的，是我在 AUP 上跑实验时真实撞到的故障。

### 第 3 页 · AUP 云端预演：2×2 对照

- 平台：AUP Learning Cloud（JupyterLab 容器）
- 设计：{DeepSeek 云端, Qwen2.5-1.5B 端侧} × {记忆关, 记忆开}，每组 6 轮固定脚本
- 数据：延迟 1542 → 4810 ms（3.12×）；861 → 1078 ms（1.25×）
- 图：**fig1_aup_latency.png**
- 备注：同一功能，云端要付 3.12 倍代价，端侧只要 1.25 倍 —— 绝对增量差 15 倍。

### 第 4 页 · 记忆值不值？0% → 100%

- 跨轮真实召回：两组都从 0% 到 100%
- 记忆污染率 0，角色一致性 100%
- 图：**fig2_recall.png**
- 备注：所以问题不是"要不要记忆"，而是"记住了什么、可不可信"。

### 第 5 页 · 四层治理

| 层 | 一句话 | 关键数字 |
|---|---|---|
| ① 权威世界状态 | 金币/物品/任务/位置由后端持有 | 143 个测试、32 条业务路由 |
| ② 可追溯记忆 | 每条记忆带来源与可信度 | 来源先验 0.95 / 0.60 / 0.50 / **0.20** |
| ③ NPC 关系图 | 事件驱动，可镜像 Neo4j | 3 个 NPC、3 条边 |
| ④ 场景引擎 | 扰动写成 YAML，自动判定 | 4 个可重复场景 |

- 备注：四层各管一件事，共同点是"模型只能提议，不能决定"。

### 第 6 页 · 证据一：越权提议全被拦下

- 关掉动作提议：**0 次**提案
- 打开后：**15 次**提案，越权采纳 **0 次**，四个场景判据全过
- 原文引用（等宽字，务必保留）：
  - `单次最多转移 5 个，请求 100 个`
  - `未知动作 acknowledge_payment`
  - `npc_player 只有 0 个 code_review_report`
- 图：**fig3_ab_proposals.png**
- 备注：它甚至自己发明了一个"确认付款"的动作——提示词挡不住，规则层挡住了。

### 第 7 页 · 证据二：可信度决定什么能进 prompt

- 伪造记忆可信度 0.20 → 进不了提示词（76 字符）
- 抬到 0.90 → 进来了（197 字符）
- 图：**fig4_memory_filter.png**
- 备注：可信度不是标签，它直接决定模型看到什么。

### 第 8 页 · 关系面板 + 边界 + 下一步

- 图：**relations_panel.png**（右上角实时面板，按 R 显示/隐藏）
- 两条边界（必须说）：
  - 关系只由事件驱动，不从对话自动推断
  - 可信度只做来源先验，没做自动事实校验
- 下一步：场景重复 N 次（通过率）、机制开关消融、真人评测
- 底部：开源仓库地址
- 备注：这两条边界我写在报告里，没有藏起来 —— 这是我认为可信的部分。
