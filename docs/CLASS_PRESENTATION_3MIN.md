## 正文

各位老师、同学好。我的结题项目是《CyberTown-EdgeCloud：面向可交互 AI NPC 的端云协同推理与记忆增强研究》。

项目是 Godot 4.5.2 的 2D 赛博小镇，后端用 FastAPI 加 HelloAgents。一套接口可切换两种部署：云端调 DeepSeek，端侧在 AMD R9700 上跑本地 Qwen2.5-1.5B。

我想回答三个问题：加长期记忆能不能让 NPC 跨轮记住玩家？代价是多少延迟？代价随部署位置怎么变？

[切第 2 张]

方法是 2×2 消融。四组共用同一批 NPC 和同一套六轮脚本，每组开测前清空记忆库。

结果是：跨轮召回，无记忆全部 0%，有记忆全部 100%。代价却差一个数量级：云端从 1542 涨到 4810 毫秒，**3.12 倍**；端侧从 861 涨到 1078 毫秒，只有 **1.25 倍**。

为什么差这么多？我在本机做了受控对照：同机器、同模型，**只换 embedding 的位置**——远程 2.10 倍，本地 1.12 倍。贵不贵取决于 embedding 在哪跑，不在设备快慢。

分阶段计时还暴露了一件反直觉的事：**每轮其实调了两次模型**——一次生成回复，一次判断该不该改好感度。在 CPU 上，后者的 prompt 要塞进整段对话，耗时是生成的两倍。所以端侧优化应该先砍分析用的 prompt。

还有个意外：同样无记忆被追问，DeepSeek 说"我一时对不上号了"，1.5B 却说"当然记得，你在做一个多智能体系统的研究"。这句抄自它的提示词示例。小模型不是不知道，而是**自信地编错**。

[切第 3 张]

我做了两处加固：好感度、金币这类状态，**模型只能提议，由后端规则裁决**；记忆改成按玩家隔离。行为探针还抓到两条读代码看不出来的跨玩家泄露。

一句话总结：**记忆在端侧几乎免费，在云端很贵；而小模型缺记忆时会骗人，更不该让它直接改状态。**

谢谢大家。

## 备用问答

**Q：1.25 倍和 3.12 倍的比较公平吗？两个模型基线差很多。**

A：绝对值不能直接比，但**相对倍数**是各自模型内开/关记忆的比值，基线差异已被消掉。更硬的证据是受控对照：同一台机器只换 embedder，2.10× vs 1.12×。这说明差异来自 embedding 的位置，而不是模型或设备。

**Q：为什么 CPU 上"分析"比"生成"还贵？**

A：因为每轮其实调了两次模型：一次生成 NPC 回复，一次把玩家消息和回复一起喂进去，判断好感度该不该变。第二次的 prompt 里塞了整段对话，而 CPU 的瓶颈在 prompt 预处理，不在逐字生成。所以设备越慢、越该先削减分析用的 prompt —— 这是一条可以直接落地的优化建议，而不是参数调优。

**Q：每组才 6 轮，延迟差异可信吗？**

A：单看四组确实处于统计临界 —— 组间差 216 毫秒，标准差却有 220–280 毫秒。所以我没有宣称"记忆拖慢端侧"，只说了两件更稳的事：召回率 0%→100% 是定性差异，不依赖样本量；开销**结构**的差异是跨 12 个样本回归出来的（字数与耗时相关系数 0.96）。后来我又用 A-B-B-A 交错跑了 24 轮复现，比值稳定。

**Q：为什么小模型会说"当然记得"？**

A：它复读的是自己系统提示词【对话示例】里的那句"最近在做一个多智能体系统的项目，用 HelloAgents 框架"。反证是：DeepSeek 拿**完全相同的提示词**却回答"我一时对不上号了"——所以这是模型能力问题，不是提示词缺陷。

**Q：1.5B 那种小模型能守动作协议吗？**

A：能，但解析要容错。本机 Ollama 跑 Qwen2.5-1.5B（Q4）：**10/10 轮都输出了动作标记**，但结尾定界符几乎每次写错（写 `}>` 或多一个 `}`）。我最初的解析严格要求 `>>`，合法率 **0/10**；改成"定位标记后取第一个完整 JSON 对象"后，**10/10**。结论不是"小模型不行"，而是**约束小模型要靠容错解析加后端校验**。

**Q：规则层具体怎么"不让模型改状态"？**

A：好感度走后端四条确定性规则（非数值按 0、正向上限 10、负向上限 15、正向需 positive 证据，最后钳到 0–100）；金币和任务走**动作白名单**，模型只能用 `<<ACTION {...}>>` 提议三个动作，`grant_gold` 这类直接被判 `forbidden`。被拒绝时提议值和生效值都写进 `metrics_*.csv`，所以"模型想加 50、实际只加了 10"是可查的。

**Q：这些加固你怎么证明真的有效？**

A：三层证据。① 31 个单元测试覆盖规则与白名单边界；② 三个行为探针打真实后端：越权提示词实际增幅 −3 / −2 / +7，四类越权动作全被拒，跨玩家记忆不泄露；③ 探针**带对照组** —— 先确认 alice 自己能记住，再看 bob 能不能套出来。

第三层抓到两个单靠读代码看不出的泄露：`SimpleAgent` 实例被所有玩家共用，它的对话历史会串；记忆自动分类把含「记得」的对话写进了**全玩家共享**的向量集合。修复后集合点数 8 → 0。

边界也说清楚：那几轮模型**自己就拒绝了**越权请求，所以规则层的截断分支没被真实流量触发 —— 那条归单测。

**Q：本地游戏怎么连上云端后端的？**

A：平台端口在 JupyterHub 反代后面，需要登录 Cookie，Godot 拿不到。我在本地起了一个只监听 `127.0.0.1` 的转发代理补 Cookie —— 公网没有入口。中间还发现 Cloudflare 会拦 .NET 客户端但放行 Python，所以整套工具都走 Python 传输栈。
